# M2 software qualification

Status: **complete — G1 accepted for the declared software profile**.
All functional, supplemental, supplied-file and M0 regressions pass on the final
browser bindings. The shaped 60-minute run, independent native/browser build
comparisons and fresh extracted-runtime checks also pass.

declared in [M1-M2-PROFILE.md](../M1-M2-PROFILE.md). The tested support boundary is
[SUPPORTED-PROFILE.md](../SUPPORTED-PROFILE.md). The engine is upstream mpv 0.40.0,
FFmpeg 7.1.1 and libass 0.17.3, compiled with stock Emscripten 4.0.14. Browser
decoders and VideoFrame are unavailable during the software acceptance tests;
HTMLMediaElement playback is forbidden. No alternative playback path qualifies.

The controlled front/tail-index MP4s are each 1,157,252,207 bytes, with 1080p30
H.264 video, AAC stereo and independent flash/click signals. Exact probes,

[qualification-fixtures.json](../../results/qualification-fixtures.json).

Neither private media nor its screenshots are included in the archive.

## Sustained measurement

`tests/m2-long.mjs` records a real hour of full-resolution playback. It samples
flashes from decoded/composited canvas pixels and clicks from decoded PCM in the
AudioWorklet, mapping audio samples through `getOutputTimestamp()`. This is
independent of mpv's reported `avsync`. It measures browser output timelines,
not physical scanout, display response or loudspeaker propagation.

Only the first five seconds after startup and explicit file-loop/seek
discontinuities are excluded. Missing signals, drops, audio underruns and
invalid timing data remain visible. The ten-minute frame-delivery window and
memory plateau criteria are declared before the run. Process-family RSS is
sampled for the launched browser, including its GPU/utility processes; summing
RSS can count shared pages more than once and is not unique physical memory.

The final shaped run lasted **3607.913 seconds**. Its 3590 matched flash/click
pairs measured **18.772 ms p95 and 25.239 ms maximum** absolute error. Two
unmatched flashes and one unmatched click remain reported; no timestamps were
invalid. The 604.057-second delivery window presented 18,116 frames with zero
drops. Across the whole hour, 108,182 frames were presented with zero VO or
decoder drops.

Wasm heap remained at 128 MiB and the HTTP cache at 16 MiB. Browser-family
nearest-rank median RSS decreased from 575.9 MiB in minutes 10–20 to 510.7 MiB
in minutes 50–60 (65.2 MiB lower); peak RSS was 1118.2 MiB. RSS reflects OS page
residency and may count shared pages repeatedly. The two explicit file loops
produced 298 and 296 underrun callbacks respectively; there were no additional
steady-playback underruns. Looping is not claimed to be gapless.

Browser-process CPU time measured 56.2% of one core at the median, 82.1% p95
and 94.2% maximum. The Mac remained on AC power at 100% battery. `pmset`
reported no recorded thermal/performance warning or CPU power status; actual
physical temperatures and throttling were not independently measured. The
network origin verified 10 Mbps body pacing and an 80 ms response delay before
and after the run. This is the declared application-layer loopback emulator,
not a WAN/TLS performance claim. Chrome exited normally with code zero.

Earlier attempts remain separate. An unshaped hour passed its measured checks
but did not meet the required network condition; it is exploratory evidence
under `results/m2/unshaped-60min/`. One earlier run ended after 2255.840 seconds
when its page/browser closed, with the cause unconfirmed. A later shaped run
ended after approximately 35½ minutes around the conversation interruption.
Those attempts remain failed under `interrupted-37min/` and
`interrupted-shaped-35min/`; their samples are not combined with the accepted
hour.

Evidence: [summary](../../results/m2/long.json),
[raw samples](../../results/m2/long-raw.jsonl), and
[paired output signals](../../results/m2/long-sync-pairs.json). The summary records
hashes of every runtime JavaScript/Wasm file used during the run.

  `5ef7415ba3161fb39b727c74862577ccf9a38e4bbd65996db5cbdff9da209c5c`.

The [native comparison](../../results/m2/reproducibility.json) verifies artifacts,
source/patch/configuration inputs and toolchain records. Original native build
manifests preserve the browser snapshot copied into those builds. The subsequent
authorization-ID, format-specific preroll and diagnostic updates change only
browser sidecars; two independent
[browser assemblies](../../results/m2/bindings-reproducibility.json) record the
final TypeScript and JavaScript files separately. Runtime hashes and the release
manifest join these two build products.

`scripts/package-baseline.py` requires every acceptance result to pass, a full
60-minute result and unchanged runtime hashes before creating an accepted
versioned archive. The archive contains the engine, browser application and
integration example, original source/bindings, build scripts, pinned dependency
manifests, patches, notices, fixture recipes and raw validation evidence. The
user's media and private screenshots are excluded.

M3/WebCodecs and later decoder work are outside this delivery. G1 acceptance
does not itself authorize a production browser-decoder fork.

## Extracted release check

A freshly extracted candidate archive was served on a separate localhost port
and tested in a fresh Chrome profile. Cold engine initialization (constructor
to `ready`) took 863.3 ms; the subsequent local fixture reached measured
Canvas/PCM output in 221.3 ms. Browser-process launch took 2449 ms separately.
This is a fresh browser profile on loopback, not a cold operating-system disk
or shared-cache measurement. Playback, exact seeking, cleanup and the
standalone integration example passed.

The final archive refreshes documentation and evidence after that check.
`release-smoke.json` identifies the tested candidate and every validated runtime
and fixture file; each is hash-identical in the final archive. Final extraction
also verifies the complete file manifest. Two independently packaged native
builds produce byte-identical versioned archives. See
[release-smoke.json](../../results/release-smoke.json) and
[release-reproducibility.json](../../results/release-reproducibility.json).
