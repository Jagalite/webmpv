# M4 optional decoder qualification

Status: implementation accepted with the user-approved 57:38 endurance
exception; see [current candidate acceptance](CANDIDATE.md). The original strict
optional long-run result remains failed. No new release is published. The user
authorized proceeding despite M3's CPU-benefit result. Software remains the
default and separately linked. Earlier statuses below are chronological evidence.
See [the contract](../M4-CONTRACT.md).

The optional native decoder uses mpv's existing decoder-selection/filter seam.
A dedicated browser worker accepts owned H.264 access units and returns bounded
CPU planes. NV12 is normalized to planar I420 before mpv's existing scaler,
filters and libass composition. Native keyframe replay recovers through FFmpeg
without presenting already-delivered frames again. The owner browser frame is
removed during player destruction to dispose of the complete worker tree.
