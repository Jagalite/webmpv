# S1 fixed segmented VOD acceptance

S1 passes its functional contract for the declared synthetic Chrome profile.
Finite HLS TS/fMP4 and single-period static DASH run through the software engine.
TS and fMP4 timestamp-reset discontinuities now support forward/backward seeks
and continuous playback. The accepted 0.2.0 archive remains unchanged; this is
additional development-checkout qualification, not a replacement G1 release.

## Clean candidate requalification

The independently built software candidate passes the [format matrix](../../results/s1/browser-2026-09-07T17-58-34.795Z/result.json), [timeline checks](../../results/s1/timeline-2026-09-07T17-59-28.755Z/result.json), and [cancellation and twenty lifecycle checks](../../results/s1/lifecycle-2026-09-07T18-00-18.607Z/result.json). Current hashes and scope are in [checkpoint.json](../../results/s1/checkpoint.json). The same software candidate subsequently passed strict foreground G1, including the full hour; see [candidate acceptance](CANDIDATE.md). All [40 current unit checks](../../results/s1/clean-candidate-unit.log) pass, covering the resource loader, ranges, audio, decoder ownership and fixture accounting.

The [first clean-candidate attempt](../../results/s1/browser-2026-09-07T17-50-24.391Z/result.json) failed fixture request accounting after successful playback and worker teardown. A response could close while asynchronous file stat was pending, before the close listener was installed, leaving a phantom active count. Socket inspection showed only the listening socket. The fixture now checks for an already-destroyed response before counting it. A deterministic regression fails before the fix and passes after it; both logs are retained as `results/s1/server-unit-before.log` and `server-unit-after.log`. Player code and binaries did not change for this correction.

## Fixes and retained failures

The original [TS timestamp-reset failure](../../results/s1/timeline-2026-09-07T15-14-52.910Z/result.json)
reached the 24-second end while seeking to 13 seconds. Native FFmpeg now maps
packet byte positions to playlist periods despite AVIO read-ahead, normalizes
period timestamps, and seeks from the period boundary to establish its origin.
The browser resource loader does not concatenate or retimestamp media.

The pinned MOV seek-index backport clears stale fMP4 sample offsets after an
AVIO reset. Earlier partial patches and failed builds remain as historical
evidence. Intermittent retained workers also reproduced after a pthread-drain
attempt. Player teardown now drains native cleanup and removes a disposable
same-origin owner frame, disposing of the entire worker tree. The final owner
lifecycle checks above supersede those failed teardown attempts.

## Reproduce

Generate fixtures with `python3 scripts/make-s1-fixtures.py`. Run
`node scripts/serve.mjs`, `node scripts/media-server.mjs` and
`node scripts/s1-media-server.mjs` in separate terminals, then:

```sh
npm run build
node --test tests/resource-loader.mjs tests/range-reader.mjs tests/audio-worklet.mjs
npm run test:segments
HEADED=1 RESULT_DIR=results/s1/new-m0 node tests/m0.mjs
```

S1 browser tests default to visible Chrome. HEADLESS=1 is a debugging override.
Preserve the accepted archive and the older M2 evidence when rebuilding.
